[v] OBJETIVO DO PROJETO
O objetivo deste projeto é criar um site interativo sobre o Sistema Solar. Nós queremos despertar o interesse das pessoas por astrologia de uma maneira acessível, oferecendo uma boa experiência para o público-alvo.

[v] DESCRIÇÃO DO PROJETO
Este projeto envolve a criação de um site interativo sobre o Sistema Solar. O objetivo é informar as pessoas e ao mesmo tempo despertar o interesse delas por astrologia. A ideia principal é ter um mapa clicável, onde cada planeta pode ser selecionado e leva o usuário para uma página especial com informações detalhadas. Nessas páginas, vamos falar sobre coisas como temperatura, tempo de rotação e translação, curiosidades e aspectos gerais de cada planeta. Queremos que o conteúdo seja claro e fácil de entender, mesmo para quem não sabe muito sobre o assunto. Além disso, o site vai ser feito para que as pessoas possam navegar de forma fácil e dinâmica. A escolha do tema do espaço se deve ao fato de que muita gente, especialmente os jovens, se interessa muito por este assunto. Dessa forma, o projeto combina tecnologia e educação em uma plataforma digital. Vamos usar imagens e organizar o conteúdo de uma maneira que seja agradável de ver. Também vamos seguir boas práticas de desenvolvimento para garantir que o site funcione bem.

No geral, o projeto busca tornar a informação em algo interessante e interativo. Além da parte informativa, o projeto também tem uma proposta para engajar o público. A ideia é incluir elementos relacionados ao tema espacial, como sugestões de produtos ou conteúdos adicionais que façam a experiência do usuário mais completa. Isso pode incluir itens temáticos, referências culturais ou até mesmo conteúdos inspirados em astrologia, aproximando o visitante do tema de forma mais descontraída. O objetivo não é apenas informar, mas também criar uma conexão com o usuário, tornando o site mais atrativo e memorável. O trabalho em equipe é importante, onde cada pessoa contribui com uma função específica, garantindo a organização e qualidade do projeto. O desenvolvimento envolve desde a criação do layout até a implementação do código e produção dos textos. Essa divisão de tarefas permite maior eficiência e colaboração entre os participantes.

[v] FINALIDADE DO PROJETO
A finalidade do projeto é ser algo além de informativo, como também interativo e que chame a atenção de pessoas interessadas no assunto. No geral, há um público-alvo, que são as pessoas que possuem interesse em aprender mais sobre astrologia de uma maneira divertida e descontraída. Dessa forma, conclui-se que o projeto deseja chamar a atenção de um grupo social, em especial o grupo de estudantes e jovens que desejam aprender e que tem interesse no tema.
